ConnectWise Timesheet Helper

1. Extract this ZIP into a permanent folder on your computer.
2. In Brave, open brave://extensions. Turn on Developer mode.
3. Click Load unpacked and select the extracted folder containing manifest.json.
4. Pin ConnectWise Timesheet Helper from the browser Extensions menu.
5. Open the helper. At the top, enter your exact ConnectWise display name
   under Ticket Owner and click Save Ticket Owner.
6. Sign in to ConnectWise with your own account and open the helper there.

The saved owner stays until you manually replace it in the settings form.
Clearing draft inputs and submitting work do not remove it. Uninstalling the
extension or deleting browser extension data can remove local settings.
Assign Me uses your signed-in account; the helper verifies the saved owner.

Company/Site defaults are Example Public Schools. This build targets
na.myconnectwise.net. No Node.js or separate agent is needed for the GUI.
Use actual work dates/times/notes. Check the runner's saved-record result.
Final automated completion has not yet been verified in production.

Find and open by title text accepts a reference from the original platform.
It requires exactly one matching title at Example Schools and never creates a
replacement when no match exists. Use an exact ConnectWise number if ambiguous.
End-of-day email update lets you enter notes/next steps and choose each ticket's
status. Update statuses and generate email saves/ verifies every status first.
Copy email table pastes into your own email composer; the helper sends no email.

For an update: replace files in this same folder and click Reload on the
extension page. Keep the same folder to preserve its extension identity.

Daily runs: upload or paste daily JSON in Daily/ Weekly TimeSheets and EoD. DAILY-EXAMPLE.json is non-submittable example data. Use actual records. After all saves verify, the runner provides Copy email table and Download HTML. Email is never sent automatically.


Unified ticket form: School is optional. Enter a ticket number and/or title text; the number is tried first. A missing number can fall back to one open title match. Use Also enter one time entry for time. Text boxes grow automatically.

Ticket time: click + Add a Time Entry for each separate time record; Remove entry removes only that draft. Mark ticket as applies after all time records are saved and verified. Draft entries remain when the popup is closed.
