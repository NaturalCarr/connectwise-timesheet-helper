CURRENT RELEASE: 0.9.21

ConnectWise Timesheet Helper

1. Extract the ZIP into a permanent folder.
2. In Brave, open brave://extensions and enable Developer mode.
3. Choose Load unpacked and select the folder containing manifest.json.
4. Pin the helper, sign in to ConnectWise and select the intended ConnectWise tab.
5. Save your exact ConnectWise display name as Ticket Owner.
6. Open Settings and enter your own company, site and other exact labels.
   Shared defaults are fictional.

For updates, replace files in the same folder and click Reload on the extension
page. Preserve that folder to retain the extension identity and local settings.

Use Find or Create Ticket with a ticket number or title text. A number takes
priority. Imported references search title text without company/site filters.
Multiple or unverified matches stop; a verified no-match can create a ticket.
Use + Add a Time Entry for each time record.

In Multi-Ticket (Timesheets and Reports), paste/upload JSON and click Validate
JSON. Review the preview, then Save tickets & time + generate Daily Report
updates. Use actual work dates, times and notes.

Preview / copy Daily Report from JSON is available after validation, before
submission finishes. Requested statuses are not proof of saved records. DITL
work is included; Payroll Wrap and lunch are excluded. Reports support inventory,
document cameras and linked recommended purchases in a bordered table. Clipboard
icon buttons copy the formatted report. No email is sent automatically.

Daily Reports default to the newest available report date. Use the calendar to
select another date. Dates without reports clear the preview and disable copy.
Inventory, document-camera and purchase edits stay tied to their report date.

History & Resume separates Saved runs, Verified time and Daily Reports. Resume
the original stopped run rather than submitting its full JSON again. Fully
confirmed tickets are skipped; partial/uncertain time is duplicate-checked.
Read saved-record results before treating work as submitted.

Download Example Files provides fictional examples. AGENTS.md explains JSON
preparation. Keep actual work records, staff details, local history, credentials
and browser profiles out of shared packages.
