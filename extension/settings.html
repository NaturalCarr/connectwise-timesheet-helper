Ticket defaults

Enter the exact labels used in ConnectWise. These settings stay in this browser profile until you change them. Saving does not modify ConnectWise or existing run plans.

School acronyms

Add your own acronyms and exact ConnectWise Company/Site labels. No schools are built in. Edit a row or remove it, then save. The same acronym can be used for different clients.

For CLI use, save the downloaded file as ticket-settings.json, or pass its path with --settings. The extension uses your saved configuration without editing packaged files. Ticket Owner is managed separately at the top of the popup.
